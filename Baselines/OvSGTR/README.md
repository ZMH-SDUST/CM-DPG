# OvSGTR

This project uses or refers to **OvSGTR**, associated with the fully open-vocabulary scene graph generation work **From Data to Modeling: Fully Open-Vocabulary Scene Graph Generation** and the released implementation for **Expanding Scene Graph Boundaries: Fully Open-Vocabulary Scene Graph Generation via Visual-Concept Alignment and Retention**.

We sincerely thank the authors for their contribution to fully open-vocabulary scene graph generation. Their work provided an important reference for this project.

Project repository: [gpt4vision/OvSGTR](https://github.com/gpt4vision/OvSGTR)

Related paper/code page:

- arXiv: [Expanding Scene Graph Boundaries: Fully Open-Vocabulary Scene Graph Generation via Visual-Concept Alignment and Retention](https://arxiv.org/abs/2311.10988)
- arXiv: [From Data to Modeling: Fully Open-Vocabulary Scene Graph Generation](https://arxiv.org/abs/2505.20106)

In our experiments, we did not modify the model hyperparameter configuration from the referenced method. Unless otherwise stated, the model settings and hyperparameters were kept consistent with the original description or released implementation used for comparison.

If you use this project or the referenced method, please also cite the original paper above.
