# SVRP

This project uses or refers to **SVRP**, introduced in the paper **Towards Open-Vocabulary Scene Graph Generation with Prompt-Based Finetuning**.

We sincerely thank the authors for their contribution to open-vocabulary scene graph generation. Their work provides an important reference for evaluating and developing scene graph generation methods under open-vocabulary settings.

Code repository: The GitHub code repository is no longer available.

Paper links:

- arXiv: [Towards Open-vocabulary Scene Graph Generation with Prompt-Based Finetuning](https://arxiv.org/abs/2208.08165)
- Papers With Code: [Towards Open-vocabulary Scene Graph Generation with Prompt-Based Finetuning](https://paperswithcode.com/paper/towards-open-vocabulary-scene-graph)

In our experiments, we did not modify the model hyperparameter configuration from the referenced method. Unless otherwise stated, the model settings and hyperparameters were kept consistent with the original description or released implementation used for comparison.

If you use this project or the referenced method, please also cite the original paper above.
