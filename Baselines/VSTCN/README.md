# Motifs+VTSCN

This project uses or refers to **Motifs+VTSCN**, based on the paper **Bridging Visual and Textual Semantics: Towards Consistency for Unbiased Scene Graph Generation**.

We sincerely thank the authors for their contribution to unbiased scene graph generation and visual-textual semantic consistency. Their work provided an important reference for this project.

Code repository: [Nora-Zhang98/VTSCN](https://github.com/Nora-Zhang98/VTSCN)

Paper link:

- IEEE Xplore: [Bridging Visual and Textual Semantics: Towards Consistency for Unbiased Scene Graph Generation](https://ieeexplore.ieee.org/document/10502321/)
